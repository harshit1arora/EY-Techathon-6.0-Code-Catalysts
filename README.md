# EY Techathon 6.0 - Code Catalysts

Full-stack application combining Tata Bot Loan Buddy frontend with MCP Server Tata Capital backend.

## Project Structure
```
├── frontend/          # Tata Bot Loan Buddy UI
├── backend/           # MCP Server Tata Capital API
└── README.md
```

## Setup Instructions

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Backend Setup
```bash
cd backend
npm install
npm start
```
